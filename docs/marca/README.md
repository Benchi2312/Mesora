# Identidad visual de Mesora

La marca elegida es **Enlace refinado**, la opción A. Su símbolo es una M
abierta, de dos trazos redondeados, que representa la conexión del equipo.
La versión principal combina el símbolo oscuro con una placa naranja.

![Logo de Mesora para fondo oscuro](./kit-mesora/logo-oscuro.svg)

Abre la [presentación de las variantes](./kit-mesora/presentacion.html) para
ver el logo sobre distintos fondos y en tamaños pequeños. Los archivos editables
están en el [kit de marca](./kit-mesora/README.md).

La [propuesta anterior](./propuesta.html) se conserva como referencia histórica.
La selección visual no constituye una búsqueda registral ni garantiza la
disponibilidad de la marca. La
[revisión preliminar del nombre](./REVISION_PRELIMINAR_NOMBRE.md) encontró usos
de «Mesora» en otros productos para restaurantes; conviene aclararlos antes
de ampliar la promoción.
