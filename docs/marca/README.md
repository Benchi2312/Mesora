## Descripción accesible

El símbolo es un cuadrado naranja de esquinas redondeadas. Dentro tiene una M
negra de grosor uniforme y extremos redondos: dos trazos verticales unidos por
dos diagonales. Evoca la conexión entre atención y preparación. A la derecha
aparece «Mesora» en letras gruesas y suaves, blancas o negras según el fondo.
No hay degradados ni detalles pequeños que desaparezcan en el móvil.

## Archivos

- [Logo para fondo claro](./logo-claro.svg).
- [Logo para fondo oscuro](./logo-oscuro.svg).
- [Versión monocroma](./logo-monocromo.svg).
- [Símbolo](./simbolo.svg), usable como base de un futuro favicon.

Los SVG tienen fondo transparente salvo la placa del símbolo. Las letras se
convirtieron a trazados a partir de Segoe UI Bold instalada en el equipo; no se
incluye ni redistribuye el archivo de la fuente. No dependen de Google Fonts
ni de una descarga externa. El monograma se dibujó como vector editable.

## Reglas propuestas

- Naranja `#FF9500`, carbón `#0D0F12` y blanco `#FFFFFF`.
- Mantener un margen libre mínimo de 24 unidades alrededor del símbolo de 96.
- Usar el símbolo solo en espacios menores de 120 px; logo completo desde 160 px.
- Para impresión de recibos, usar la variante monocroma.
- Conservar proporciones. Evitar contornos, efectos 3D o sombras añadidas.
- Dar al enlace de inicio el nombre accesible «Mesora, inicio»; ocultar el SVG
  a lectores de pantalla si ese mismo nombre ya existe como texto en el enlace.

Antes de adoptarlo, aprobar la propuesta y comprobar la disponibilidad de la
marca con el propietario. No se ha realizado una búsqueda registral.
