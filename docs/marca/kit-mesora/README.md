# Kit de marca Mesora: Enlace refinado

Opción A elegida por el propietario. El símbolo es una M abierta formada por
dos trazos con extremos redondeados. La placa naranja identifica la aplicación.
Los SVG son editables y se pueden ampliar sin perder calidad.

## Versiones

- [Presentación de fondos y tamaños](./presentacion.html).
- [Logo para fondo claro](./logo-claro.svg) y [fondo oscuro](./logo-oscuro.svg).
- [Logo monocromo](./logo-monocromo.svg) para aplicaciones de una tinta.
- [Isotipo naranja](./isotipo-naranja.svg), para aplicaciones e iconos.
- Símbolo transparente en [negro](./simbolo-negro.svg) y [blanco](./simbolo-blanco.svg).

Colores principales: naranja `#FF9500`, carbón `#0D0F12` y blanco `#FFFFFF`.
Mantén las proporciones, deja espacio alrededor y usa el isotipo cuando el
logo completo resulte demasiado pequeño. Las letras están convertidas a
trazados a partir de Segoe UI Bold; los SVG no requieren fuentes externas.
La selección visual no sustituye una comprobación de disponibilidad registral.
